Holiday Home Rental

In this example the dialog box automatically calculates the price for a reservation as you set the date. The price is $10 per day, with double prices on weekends. The system can also handle advanced pricing that takes into account the time left to book and the type of rental selected. For the purpose of this demonstration everyone can edit all reservations.

You can also view this schedule on a mobile device
